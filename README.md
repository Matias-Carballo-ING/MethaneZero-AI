## Cómo ejecutar el prototipo
1. Instalar dependencias:
   `pip install -r requirements.txt`
2. Abrir **LM Studio**, cargar un modelo instructivo (ej. `Llama-3.2-1B-Instruct` o `Llama-3.2-3B-Instruct`) y encender el servidor local en el puerto `1234`.
3. Iniciar la aplicación:
   `streamlit run MethaneZeroAI.py`
